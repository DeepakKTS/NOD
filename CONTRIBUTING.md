# Contributing to Nod

Nod is a hackathon build with an unusually explicit operating contract. Most of
what a contributor needs is in [`CLAUDE.md`](CLAUDE.md) — read it before the
code. It is the project's memory, and §5 in particular is a list of real defects
this repository shipped and the checks that now catch them.

## The short version

```sh
make install          # pinned toolchain, extras, and the git hooks
make gate             # lint, types, tests + coverage gate, bench smoke
make bench            # full benchmark offline, no API key needed
```

**`make gate` is not hermetic.** Two tests pace audio in soft-real-time; on a busy
machine EC-37's drift guard voids the run with `FeederDriftError: ... run is void`,
which is the guard working and not a code failure. Quieten the machine and re-run.

**Run `make gate` alone.** Never in a pipeline, never in an `&&` chain. A
pipeline's exit status is its last command's, so `make gate | tail` reports
`tail`'s success and a red gate reaches the commit. That happened three times
here before the check moved into `.git/hooks/pre-commit`, where `make gate`
stamps `.gate.ok` with the working tree's hash and the hook refuses any commit
that does not match. `make hooks` installs it; run it once.

## What a pull request is expected to carry

- **Tests with the code, not after.** A branch added to the control law without
  a test that exercises it is incomplete.
- **A test that has been seen red.** Revert the change it guards, run it,
  confirm it fails, restore. A test that passes in both states documents
  behaviour rather than protecting it, and reads as coverage it does not have.
  For anything in the first tier below, do this through `make mutate` and add
  the mutation to `CATALOGUE` in `tools/mutate.py` rather than by hand.
- **One concern per commit**, conventional prefixes: `feat(core):`, `fix(bench):`,
  `docs:`, `refactor:`, `test:`, `chore:`.
- **An ADR** in [`docs/DECISIONS.md`](docs/DECISIONS.md) for any structural
  decision a later session would otherwise re-litigate. Five lines, matching the
  format already there.

## Where the coverage goes

Coverage here is **deliberately uneven**, and CLAUDE.md §5 says where. Full
mutation discipline is non-negotiable on the arbiter's two gates, `policy.py`,
the two named paths in `proxy.py`, and anything that feeds a published number —
the metrics, the quantile definition, the corpus ground truth, the arm
configurations, the provenance labelling. Those fail *invisibly and in the
flattering direction*: a wrong number prints a plausible one. The console, the
adapters and the rest of the server plumbing are accepted thinner, because they
fail visibly. Cut from the second list when time is short and say so in the
commit; do not dilute the first.

## The invariants

Nine of them, at CLAUDE.md §2. Breaking one is a bug even if the tests pass. The
two that catch people first:

- **INV-7 — tests never touch the network.** Unit and integration tests run
  against `FakeAssemblyAI`, replaying recorded `.jsonl` fixtures. Anything
  needing live credentials is `@pytest.mark.live` and excluded from CI.
- **INV-9 — no number in any document is hand-written.** Every benchmark figure
  in the README or the docs is generated by `make bench` from committed traces,
  into a machine-owned region that a test compares against the committed run.
  Edit the region and the suite goes red, which is the intent.

## Claims

The README carries a "Prior art and honest scope" section, and it is load-bearing
rather than decorative. Nod is **not** the first adaptive endpointer — AssemblyAI's
own Voice Agent API ships adaptive pacing. Nod is an open one on the streaming STT
path with the policy written down and the numbers published. Do not add a claim
that `make bench` cannot regenerate, and do not soften a negative result: this
project has published a wrong headline once (ADR-054) and corrected it in public
(ADR-055), and that record is worth more than a clean story.

Nod adapts to pauses. It does not interpret them. Any feature that scores a person
from their hesitation — emotion, stress, honesty, a clinical condition — is out of
scope permanently, and that is not negotiable for a contribution.
